# Plumber Growth Website Template Documentation

This directory holds the numbered foundation documents for the **Plumber Growth Website
Template** — the reusable Next.js plumbing website behind the Plumber Growth System. The
documentation set is planned as a sequence of 20 authoritative specifications (`00`–`19`),
authored and approved in numeric order. Only approved, existing documents are linked below;
this index is the reading order and single source of truth for documentation status.

## Status legend

| Status | Meaning |
| --- | --- |
| Complete | Approved file exists in the repository |
| Draft | File exists but has not been approved |
| Planned | File has not been authored |
