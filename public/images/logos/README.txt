USAGE
Use the horizontal primary logo whenever space allows. Use the icon for
favicons, social profiles, app icons, or other small spaces. Do not stretch,
recolor, rotate, rearrange, or add effects to the logo.

PRODUCTION NOTE
These files are high-resolution raster assets. Have the approved logo redrawn
as true vector artwork before vehicle wraps, large signage, engraving, or
embroidery production.
